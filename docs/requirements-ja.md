# FFmpeg.wasm 動画編集アプリ 要件定義書

## 1. 概要

本システムは **FFmpeg.wasm** を用いて、ブラウザのみで完結する動画編集アプリケーションである。サーバーを利用せず、ローカル環境（ブラウザ）内で編集・書き出しを行う。

---

## 2. 必要機能

### 2.1 クリップ編集

- トリム（開始・終了位置の指定による切り出し）
- 分割・結合（複数動画の連結）

### 2.2 画面操作

- リサイズ（プリセット: 1:1, 9:16, 16:9, 4:5）
- クロップ（領域指定による切り抜き）
- 回転・反転（90°回転、左右反転）

### 2.3 速度・トランジション

- 倍速・スロー再生（0.5〜2倍速）
- フェードイン・フェードアウト（映像・音声）

### 2.4 オーディオ編集

- ミュート、音量調整
- BGM 追加（映像音声とのミックス）
- 外部音声差し替え

### 2.5 オーバーレイ

- テキスト挿入（タイトル、字幕など）
- 画像ロゴ・透かしの追加

### 2.6 サムネイル生成

- 任意フレームの静止画生成
- 等間隔の連続サムネイル生成

### 2.7 書き出し

- 無劣化コピー（入力と同一コーデックの場合）
- WebM（VP9 + Opus）形式を標準出力
- MP4（H.264 + AAC）は実験的対応（短尺推奨）

---

## 3. UI 要件

### 3.1 画面構成

- ヘッダー：新規／開く／保存／書き出し
- プレビュー領域：アスペクト比切替、プレビュー再生
- 左ペイン：メディアライブラリ（動画／画像／音声）
- タイムライン：1トラック（映像）＋1レーン（BGM）
- 右ペイン：クリップのプロパティ編集（トリム、速度、音量、テキスト等）

### 3.2 操作性

- ドラッグ＆ドロップによるファイル追加
- タイムラインでのカット位置指定
- プロパティパネルで各種調整

---

## 4. 技術要件

- **FFmpeg.wasm** を Web Worker 上で実行（UI スレッドをブロックしない）
- ファイル I/O は `ffmpeg.FS` と **File System Access API** を利用
- プレビュー再生は **HTMLVideoElement / WebCodecs** を利用し軽量化
- 書き出し処理はジョブキュー化（進捗表示・キャンセル可）

---

## 5. 制約

- ブラウザ実行のため処理はメモリに依存し、大容量ファイルでは制限がある
- 再エンコードは負荷が高いため、MVP では短尺動画を想定
- 標準出力は WebM。MP4 出力は利用環境・ライセンスに依存するため「実験的機能」とする

---

## 6. 非機能要件

- シンプルで直感的に操作可能な UI
- 処理中の進捗表示（％表示）
- 異常時のエラーメッセージ表示
